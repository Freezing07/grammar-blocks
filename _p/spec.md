# 练习题内容规范（grammar-blocks 项目）

## 你的任务

为指定的关卡写**练习题数据**，输出一个 JSON 文件。不要修改任何其它文件。

- 输入：`levels/chapter-N.json`（该章所有关卡的题目、语法点、例句）
- 输出：`_p/practice-N.json`
- **每关 30 句**，一句不能少

## 输出格式

一个对象，键是关卡 id，值是这一关的练习数据：

```json
{
  "3-1": {
    "groups": [
      { "id": "np1", "label": "主语 NP" },
      { "id": "adv", "label": "频度状语" },
      { "id": "vp", "label": "谓语 VP" }
    ],
    "patterns": [
      [["pronoun", "主语", "np1"], ["adv", "频度状语", "adv"], ["verb", "谓语", "vp"]],
      [["pronoun", "主语", "np1"], ["verb", "谓语", "vp"], ["noun", "宾语", "np2"]]
    ],
    "rules": [
      "频度副词（always / usually / often / never）要放在动词前面。",
      "主语是第三人称单数，动词加 s。"
    ],
    "items": [
      { "w": ["She", "usually", "walks"], "d": { "walk": 2 }, "r": 0 },
      { "w": ["He", "reads", "books"], "d": { "read": 1 }, "r": 1 }
    ]
  }
}
```

### 字段含义

| 字段 | 说明 |
|---|---|
| `groups` | 语法树的分组。key 可以是 `"id"`、`"label"`，以及可选的 `"clause": true` 和 `"parent"`。**注意分组是整关共享的**：所有句型看到的是同一份 groups，见下面「分组的两个坑」 |
| `patterns` | 句型骨架。每个位置写 `[词性, 语法角色, 分组id]`，三者都是字符串 |
| `rules` | 3~6 条规则，中文，一句话讲清一个点。**所有 key 只能是** `"id"` 和 `"label"` |
| `items[].w` | 按骨架填的词，顺序**就是**正确答案 |
| `items[].d` | 错误形式 → 它出现在第几个位置（从 0 开始） |
| `items[].r` | 可选，指向 `rules` 的第几条（默认 0） |
| `items[].p` | 可选，用第几个骨架（默认 0） |
| `items[].c` | 可选，中文意思。写了它就变成「照中文拼句子」而不是改错题 |

| `items[].m` | 可选，行内标点：键是位置，值是标点。比如 `{"2": ".", "3": ","}` 表示第 3 块后面加句号、第 4 块后面加逗号 —— **第六章的衔接词题必须用它**（衔接词要跨句子才看得出作用） |

第六章的例子（However 用来连接两句话）：

``json
{ "w": ["He", "studied", "hard", "However", "he", "failed"],
  "d": { "Therefore": 3 }, "m": { "2": ".", "3": "," }, "r": 0 }
``

**词性只允许这 9 个**（写别的会被自检拒绝）：
`noun`（名词）、`pronoun`（代词）、`verb`（动词）、`adj`（形容词）、`adv`（副词）、
`article`（冠词）、`prep`（介词）、`conj`（连词）、`inf`（不定式符号）

## 硬性规则（自检会挡）

1. **`items[].w` 的词数必须等于它所用骨架的位置数。**
   这是最容易犯的错 —— 长度不匹配会让展开时把词性标错。
   句子长度不一样，就多写几个骨架，用 `p` 指定。
2. **`d` 里的词不能和 `w` 里的任何词相同。**
3. **`d` 里的位置必须落在 `w` 的长度范围内。**
4. **每句都要有 `d`**（除非你写了 `c`）。
   因为没写 `c` 的题会做成改错题：用 `d` 里的错误形式预填，让玩家换掉。
5. **同一个分组里的积木必须挨在一起**（比如 `np1` 的积木不能中间夹一个 `vp`）。
   嵌套的分组要连整个子树一起看：父分组 + 所有后代的积木必须是一段连续的位置。
6. 每关至少 20 句，**目标 30 句**。

## 分组的两个坑

**坑一：groups 是整关共享的，不是每句一份。**
某句用不到的分组会在语法树里变成一个空框（渲染层现在会自动跳过空分组，
但那是兜底）。要么让整关的句型都用同一批分组，要么就接受这个分组在这句里不出现。

**坑二：同一个分组在不同句型里句法角色不同，就不能给它写 `parent`。**
`parent` 表示「这个分组嵌在哪个分组里面」，语法树靠它画出从句嵌套的样子
（定语从句嵌在名词短语里 —— 第四章最值钱的视觉就是这个）。
但父节点必须是**所有**用到它的句型里都对：如果一个分组有时作主语、
有时作宾语，那没有一个统一的父节点，保持平铺才对。

反例：定语从句的先行词有时是主语 NP、有时是宾语 NP，
所以 4-4 / 4-5 拆成了两个分组 —— `rel`（`parent: np1`）和 `rel2`（`parent: np2`）。
`_p/fix-rel.js` 就是干这个的：看句型里紧挨在从句前面的是谁。

判断能不能挂：挂上去之后，父分组 + 所有后代的积木在每个句型里都还得是连续的一段。
`_p/rebuild.js` 会自动按这个判据试，试不过就保持平铺并在报告里列出来。

## 写题的要点

- **一题只错一个地方**，而且那个错必须是这一关教的语法点。
  3-1 教频度副词位置，就别在 3-1 的练习里考时态。
- **错误形式要像真人会犯的错**，不要造无意义的字符串。
  好：`The dogs runs`（主谓不一致）；坏：`The dog runly`。
- **词表要贴着原关卡**。先看 `levels/chapter-N.json` 里这一关的题目用了什么词，
  练习就用同一批词汇，不要突然冒出超纲词。
- **句子要自然**。宁可句子短一点，也不要造出「我的父亲读咖啡」这种组合。
- **`rules` 写在点子上**，是给答错的人看的：一句大白话，不要术语堆砌。

### 顺序错的题（`o`）

有些错不是「词用错了」而是「顺序错了」，这时用 `o` 写显式的错误顺序：

```json
{ "w": ["She", "gives", "me", "a", "pen"], "o": ["She", "gives", "a", "pen", "me"], "r": 0 }
```

`o` 必须和 `w` 等长，用到的词都得能在积木或干扰项里找到。

