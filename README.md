# 拖积木学英语语法（暂名）

免费、开源、游戏化的英语语法练习。核心玩法是**拖动积木拼句子**，
拼对了积木会「升起」变成结构图 —— 把抽象的语法变成看得见的东西。

**当前进度：7 章 / 57 关 / 280 个关卡句子。**
前五章是设计文档里规划好的（词性 → 句型 → 时态 → 从句 → 非谓语/虚拟/倒装/强调），
第六章补了**语篇衔接**，第七章补了**段落排序** ——
因为单句练得再好，连起来写段落时还是会卡。

另外有一个**跨关卡的错题本**：答错的句子自动收进来，练到「一次就过」才算拿下。

每一关通关之后还会解锁**练习模式** —— 同一个语法点再来几十句，
因为 5~6 句只够「知道」，不够「会」。

- 无后端、无依赖、无构建步骤
- 一个 `index.html` 双击就能跑
- 进度存在浏览器 `localStorage`

## 怎么玩

双击 `index.html`（Chrome / Edge / Firefox 都可以）。

| 操作 | 说明 |
| --- | --- |
| **拖积木** | 从积木库拖进上面的槽位；拖回积木库＝放回去 |
| **轻点积木** | 一键放进第一个空位；槽位里的轻点一下＝退回库里 |
| **提交** | 槽位填满才可点，也可以直接按 `Enter` |
| **提示** | 帮你填对一格，代价是一颗星 |
| **重来** | 这一句重新摆 |
| **进度点** | 关卡内 1~N，亮起来的是已通关的句子，可以点回去重玩 |
| **返回地图** | 顶栏按钮，回去选关 |
| **📕 错题本** | 地图右上角，答错的句子都收在这里；可以单练一句，也可以「全部重练」 |
| **练习模式** | 通关之后，关卡卡片上会多出一个按钮，同一个语法点再练几十句 |
| **🔊** | 音效开关 |

答对：积木飞起来拼成结构图，屏幕上方冒一个「✓ 拼对了」。
答错：错误的槽位抖一下并标红，**正确的那几块保留并打绿勾**，
错的积木自动退回库里；同时给一句大白话讲解 + 一个对照例句。

## 两种「结构看得见」

这是这个项目的灵魂 —— 答对之后，积木不是消失，而是**升起来变成结构**。
前六章和第七章展示的是两种不同的结构：

### 语法树（第 1~6 章）

```
                    S
          ┌─────────┼─────────┐
        NP        VP        NP
       ┌─┴─┐       │       ┌─┴─┐
     The  man     is     my  uncle
          │
       定语从句
      ┌───┼───┐
    who called (me)
```

- **从句长在它修饰的名词下面**，不是跟主句并排 —— 一眼看出它修饰谁
- 从句节点用暖黄色标出来：「这一整块是一个从句，它占的是一个位置」
- 非谓语的积木带一圈**粉色虚线**：「这个动词形式不是句子的谓语」

### 段落结构（第 7 章）

```
┌────────────────────────────────────────┐
│ 1· 主题句    Online learning is popular.│
└────────────────────────────────────────┘
        ↓ 理由
┌────────────────────────────────────────┐
│ 2· 理由      It is convenient…          │
└────────────────────────────────────────┘
        ↓ 举例
┌────────────────────────────────────────┐
│ 3· 例子      For example, you can…      │
└────────────────────────────────────────┘
        ↓ 总结
┌────────────────────────────────────────┐
│ 4· 结论      In conclusion, it saves…   │
└────────────────────────────────────────┘
```

段落排序模式里，积木是**一整句话**，槽位和积木库都改成竖排（段落是自上而下读的）。
答对之后不给语法树 —— 段落的关系不在句子内部，而在句子之间，
所以亮出来的是**逻辑链**：每句话的角色，以及句子之间靠什么衔接。

| 🔤 1-6 | 冠词 | a/an 看发音不看字母、an old house 看的是 old |
| 🧭 1-7 | 介词 | on 是表面 in 是里面、时间介词 at/in/on 分工 |

### 玩法类型

- **拼句**：默认玩法，从零把句子摆出来
- **改错**：句子里已经藏了错，槽位预先摆好，你负责把错的换掉（44 句）
- **疑问句**：句末是 `?` 而不是 `.`（15 句）
- **句群**：一关里有好几个句子，练习句子之间的衔接（第六章）
- **段落排序**：积木是一整句话，把打乱的句子排成通顺的一段（第七章）
- **Boss 限时**：每一句都有倒计时（39 句）。超时**不判错**，只记一次「超时」
  并重置倒计时，代价是一颗星 —— 允许犯错，但让你有点紧张感

### 星级与错题重练

一次过且没用提示 = 3 星；用了提示、提交两次、或超时过 = 2 星；错更多 = 1 星。
每颗星 10 XP，答对另有 5 XP 底分，每 100 XP 升一级。
关卡星级取本关所有句子的平均，显示在地图卡片上。

**本关有答错过的句子时，通关页会出现「重练答错的 N 句」**，
点进去只做那几句（进度点也会只剩那几个）。重练不计星级，但照常给 XP，
练完还会告诉你还剩几句没拿下。

### 🏋️ 练习模式

每关的 5~6 句是「例题」—— 看懂一个语法点够了，练熟不够。
所以**通关之后**，关卡卡片上会多出一个「练习模式 · 再来 N 句」的按钮。

- **形式上主要是改错题**：给出一个错了的句子，你负责把错的那一块换掉。
  不用配中文提示，而且这正是考试里最常考的形式
- **一关一组**，几十句连着做，全部是你刚学的那一个语法点的变形
- **不计星级**，但**照常给 XP**；做错的句子会自己进错题本
- 关卡没通关之前按钮不会出现 —— 先看懂例题，再上量

### ✍️ 写作提示词（练完之后，把它写出来）

练习模式练的是**认出来** —— 积木在池子里、错的那一块也指给你了。
可真正写的时候没人给你这些。所以每关还会生成一段**写作提示词**：

- 做完 30 句练习的**结算页**上直接给出来，一键复制
- 地图上每张关卡卡片也有一个常驻入口（不要求先做过练习，想写就写）
- 粘到任意 AI 对话里（网页版、App 都行）就进入一个循环：
  AI 出一句中文 → 你翻成英文 → 它批改并讲解 → 再出下一句
- 出满 10 句它自己停下来，总结你常错的规则

**应用不调用任何模型，也不联网。** 它只负责生成这段提示词，批改发生在你那边 ——
所以这个功能不依赖任何 API，也没有额度问题。代价是应用**不知道你到底练没练**：
没有完成标记、没有 XP，地图上看不出「这关的写作我写过了」。

提示词按「关卡名 + 目标 + 这一关的 rules」自动拼，51 关（第一~六章）都有。
**第七章没有** —— 段落排序练的是段落逻辑，用「翻译一句/两句」去练它不对口，宁可不做。
第六章单独用**两句翻译**的形态：那一章的语法点（however 要另起一句、a/the 是前后回指）
在单句里根本看不出作用。

提示词里有几处是特意加的，因为不写的话 AI 很容易走偏：

- **「我的译法和你想的不一样、但也是对的，要算对」** ——
  否则 AI 会拿它心里的唯一答案判错，这是这类练法最常见的坑
- **「你给的中文要明确指向目标结构」** ——
  中文有歧义的话，你可能翻出一句根本用不到这个语法点的英文，等于白练
- **一段【说话的方式】**（7 条）—— 这是给初学者用的，
  默认的 AI 语气太像教科书：答对了敷衍一句「很好」，答错了直接挑错。
  所以明确要求它**先肯定对的部分再说哪里要改**、
  **夸要夸到具体哪个词哪条规则上**、别说「显然」「很简单」这类泄气话、
  术语后面跟一句人话、emoji 别刷屏
- **反馈和总结的顺序都是「先肯定」** —— 光说「要友好」没用，
  得把顺序写死，否则 AI 还是从错误讲起

另外 Boss 关（每章最后一关）的 rules 是整章混合的，
所以额外写明了「轮着考、但一句只考一个点」，免得变成随机复习。

注意：语气要求里**不能举和具体语法点绑死的例子**。
第一版我在「夸到点上」后面写了「比如『s 加对了』」，
放到虚拟语气、倒装那些关就莫名其妙了 —— 现在改成
「指出是哪个词、哪条规则做对了」。写这段模板时要记住它是 51 关共用的。

### 📕 错题本（跨关卡）

地图右上角的「📕 错题本 N」里，N 是你**还没拿下**的句子数。

- **自动收集**：任何时候答错一句，它就进来 —— 不用你自己记是哪一句
- **跨关卡**：错题来自哪一章都混在一起，可以一次练完。
  这时进度点上显示的是关卡号（比如 3-1、5-2），免得只看到「第 4 句」发懵
- **怎么算拿下**：只有在错题本练习里**第一次就做对**才会被划掉。
  同一句当场试错两遍再做对不算 —— 那只是照抄刚才看到的答案
- **全部重练**会打散顺序，免得你靠位置记答案
- 每张卡片上都有那句中文、当时的讲解、以及你错过几次；想单练一句随时可以

错题本的判定标准和普通闯关是分开的：它**不计星级**，但**照常给 XP**。

### 存档

进度存在浏览器 localStorage 的 grammarBlocks.v2 里，结构是这样：

    {
      "xp": 640,
      "muted": false,
      "levels": {
        "1-1": { "cleared": true, "stars": 3, "rounds": { "1-1-r1": 3 } }
      },
      "pocket": {
        "3-6|3-6-r4": {
          "levelId": "3-6", "roundId": "3-6-r4",
          "n": 2, "cleared": false, "t": 1700000000000
        }
      }
    }

pocket 就是错题本：n 是错过几次，cleared 是「已经在错题本里一次做对了」，
t 是最后一次动它的时间。内容改过之后，找不到的关卡或句子会被自动跳过，
不会因为记录对不上而报错。

### 练习题的写法（紧凑格式）

练习题不写完整结构 —— 一关只声明一次「句型骨架 + 规则」，每道题写一行：

    "practice": {
      "1-1": {
        "groups": [ { "id": "np1", "label": "主语 NP" }, { "id": "vp", "label": "谓语 VP" } ],
        "patterns": [
          [["article", "限定词", "np1"], ["noun", "主语", "np1"], ["verb", "谓语", "vp"]]
        ],
        "rules": [
          "主语是单数，动词要加 s；主语是复数，动词用原形。"
        ],
        "items": [
          { "w": ["The", "dog", "runs"], "d": { "dogs": 1 }, "r": 0 }
        ]
      }
    }

- patterns 是句型骨架：每个位置写 [词性, 语法角色, 所属分组]
- items[].w 是按骨架填的词，顺序就是正确答案
- items[].d 是错误形式 → 它出现在第几个位置（同时用来生成改错题的预填）
- items[].r 指向 rules 里的哪一条讲解
- items[].c（可选）写中文意思，这道题就变成「照中文拼句子」而不是改错
- items[].p（可选）指定用第几个句型骨架，默认 0
- items[].m（可选）行内标点：`{"2": ".", "3": ","}` 表示第 3 块后加句号、第 4 块后加逗号
- groups 除了 id / label，还可以写 `clause: true`（语法树里显示成琥珀色的从句节点）
  和 `parent`（嵌在哪个分组里面）

**groups 是整关共享的，这是这套格式里唯一需要动脑的地方。** 两个后果：

1. 某句用不到某个分组时，它在这句的语法树里是空的（渲染层会自动跳过，
   不会留下空框，但那说明分组声明得不够紧）
2. 一个分组在不同句型里句法角色不同，**就不能给它写 `parent`**。
   最典型的例子是定语从句：先行词有时是主语 NP、有时是宾语 NP，
   所以 4-4 / 4-5 拆成了 `rel`（挂 np1）和 `rel2`（挂 np2）两个分组 ——
   不然同一个语法点在例题里是嵌套的琥珀树、在练习里变成一排扁平的灰框。

非谓语的粉色虚线标记不用手写：练习的骨架放不下这个标记，
但它其实是「词性 + 角色」的函数（`verb` + 不定式/动名词/现在分词/过去分词），
展开时自动推出来，所以练习的语法树和例题长得一样。

启动时这些会被展开成普通的句子对象 —— 展开之后，
判定、语法树、错题本、重练这些全都照旧工作，不需要为练习模式单写一套流程。

### 段落排序的一段（sentence 级）

```json
{
  "id": "7-2-r1",
  "mode": "order",
  "cn": "把这几句话排成一段通顺的话",
  "tip": "先说观点，再说理由，然后举例，最后总结",
  "blocks": [
    { "text": "Online learning has become very popular.", "role": "主题句（观点）" },
    { "text": "It is convenient because you can study anywhere.", "role": "理由" },
    { "text": "For example, you can watch a lesson on the bus.", "role": "例子" },
    { "text": "In conclusion, online learning saves a lot of time.", "role": "结论" }
  ],
  "links": ["理由", "举例", "总结"],
  "distractors": [
    { "text": "My brother is a teacher in a middle school.", "role": "多余的一句" }
  ],
  "explain": "…", "example": "…", "win": "…"
}
```

字段说明：

- `blocks` 的顺序**就是**正确答案的顺序
- `groups[].parent` 指向另一个 group 时，这一组**嵌在那一组下面**
- `groups[].clause: true` 把这一组标成暖黄色
- `blocks[].nonfinite: true` 给这块积木加粉色虚线，表示它不是谓语
- `marks`（可选，对象）＝**在指定槽位后面插标点**，键是槽位下标。
  靠它一关里可以放好几个句子
- `rootLabel`（可选）＝语法树的树根文字，默认 `S 句子`；句群关写 `句群`
- `mode: "order"`（可选）＝**段落排序模式**：积木是整句话、竖排、答对后给段落结构
- `links`（段落排序必填）＝句子之间的衔接关系标签，长度 = 句子数 − 1
- `distractors` 是干扰项；段落排序里最多放 1 个「多余的一句」
- `prefill`（可选）＝**改错模式**：开局按这个顺序把槽位摆好
- `timeLimit`（可选，秒）＝这一句限时，只有 Boss 关该有
- `punct`（可选）＝句末标点，默认 `.`；疑问句写 `"?"`

### 三条写进自检、手滑就会报错的规则

1. **一个组连同它的所有子组，必须占一段连续区间** —— 否则语法树
   从左到右读出来就不是原句的顺序
2. **干扰项不能和正解重名** —— 否则判定会有歧义
   （正解之间重名是允许的，比如 `I will call you if I have time` 里有两个 `I`）
3. **改错的 prefill 里每个词都必须在库里找得到** —— 否则玩家永远拼不出来

### 加一句句子 / 加一段

1. 在 JSON 里找到对应关卡，往 `rounds` 数组加一项
2. 改完跑 `node smoke-test.js`
3. 没有报错就可以刷新页面看效果

### 加一关 / 加一章

- 加一关：往某章的 `levels` 数组加一项
- 加一章：往 `chapters` 数组加一项

`node smoke-test.js --sync` 地图上就会多出来。但 Boss 关（每章最后一关、
每句都带 `timeLimit`）的标记需要自己写 `"boss": true`。

## 自检

```
node smoke-test.js            # 内容 + 结构 + 玩法，一条命令全查
node smoke-test.js --sync     # 顺便把关卡 JSON 抽到 levels/
```

它会做四件事：

1. **内容**：每关每句的字段齐不齐、词性对不对、重名、
   含子组的连续性、`parent` 指向对不对、有没有成环、
   `marks` 下标有没有越界、段落排序的 `links` 数量对不对、
   改错的 prefill 是否拼得出来、Boss 关是不是每句都限时、
   疑问句的 punct 有没有写成 `?`
2. **结构**：JS 里用到的元素 id 在 HTML 里存不存在、`els` 元素表有没有漏项、
   主脚本语法能不能过
3. **玩法**：在 Node 里用一套最小 DOM **直接跑 `index.html` 里的真脚本**，
   从地图点进去、逐句作答、答错退回、用提示、改错模式、疑问句标点、
   多句标点、**段落排序的竖排和逻辑链**、Boss 倒计时、错题重练、
   **错题本（记录 / 划掉 / 跨关卡练习）**、静音开关，
   一路自动通关 57 关，还会专门检查结构视图：
   积木有没有全落进去、左右顺序对不对、定语从句有没有真的嵌进名词短语里、
   非谓语有没有被标出来、段落关系箭头数量对不对
4. **同步**：`levels/*.json` 和内嵌数据有没有跑偏

这个自检不是摆设，它累计拦下了这些真问题：

- 四个会让页面白屏的 `els` 表漏项
- 提示顶掉积木后「积木凭空消失」
- 一处干扰项和正解重名
- 一条 prefill 里有库里根本不存在的词（玩家永远拼不出来）
- 一条规则定得过严：原来一律禁止积木重名，导致正常句子被判违规
- **按钮监听器累积**：答对后点进度点跳别的句子，再提交会同时触发
  「提交」和「下一句」—— 句子刚拼对就被跳走，语法树再也画不出来
- **练习模式里从句不嵌套、非谓语不带粉标**：练习的 groups 是整关共享的，
  原先既没抄例题的 `clause` / `parent`，骨架里也放不下 `nonfinite` 标记 ——
  同一个语法点，例题是嵌套的琥珀树、练习却是一排扁平的灰框。
  现在展开时按「词性 + 角色」自动补非谓语标记，
  从句标记由 `_p/rebuild.js` 从例题抄过来，并且只在**子树连续性成立**时才嵌套
- **语法树里的空框**：练习题用不到的分组会被画成一个空节点。渲染层现在直接跳过

## 内容管线（`_p/`）

写练习数据用得上的几个脚本，都在 `_p/` 下：

```
_p/spec.md            练习题的写作规范（字段、硬性规则、分组的两个坑）
_p/practice-all.json  所有练习题的真源（57 关）
_p/rebuild.js         合并片段 → 规范化 → 紧凑写回 index.html
_p/fix-rel.js         按先行词把定语从句拆成 rel / rel2（4-4、4-5）
node _p/rebuild.js    改完数据跑这一条就够了
```

`rebuild.js` 会顺手做这几件事（都是幂等的，可以反复跑）：

1. 骨架位置数和词数对不上时自动修
2. 表语的分组纠正成 `np2`
3. 骨架用到但 groups 里没有的分组自动补上
4. 从例题抄从句的 `clause` / `parent`，并验证嵌套之后子树仍然连续
   —— 不成立就保持平铺，并在报告里列出来

### 写作提示词有两份一样的代码

`buildWritingPrompt` 在 **`index.html` 里一份、`_p/prompt.js` 里一份** ——
因为单文件应用没有构建步骤，运行时必须自带；而 `_p/gen-prompts.js`
要用它把 51 关的文本批量导出来校对。改一处**必须同步另一处**。

这个风险由自检盯着：`smoke-test.js` 会把内嵌生成器的输出和
`_p/prompts-all.json` **逐字比对**，对不上就报错并提示你重跑 `node _p/gen-prompts.js`。

## 已知未做

- **视觉版式没有机器验证过**：逻辑和结构都跑过自检，但页面长什么样得你打开看。
  写作提示词的卡片和弹窗也在这个范围内 —— 自检只验证了「文字对不对、按钮在不在、
  点开有没有内容」，没验证它看起来挤不挤
- **写作提示词的实际效果取决于 AI**：应用只给提示词，批改质量、会不会在你说答案前
  就剧透，全看对面那个模型听不听话。自检能保证提示词里写了这些要求，
  保证不了模型照做
- **写作练习没有记录**：练没练过应用不知道，也就没有完成标记和 XP
- 拖拽是用 Pointer Events 手写的（鼠标 + 触屏同一套），没有用 dnd-kit
- 音效是 Web Audio 合成的，没有音频文件
- 语法树能嵌套了，但**连线还是一层一层直上直下**，深嵌套时可能会显得挤
- **练习题的英文是「机器查结构、人眼看内容」**：1530 句的骨架（词数对不对得上句型、
  干扰项有没有和正解撞名、词组连不连续、prefill 的词在不在词库里）全部由自检脚本把关，
  自检能过；但**句子读起来自不自然、语法点是不是真的考到了，只有抽样人读过**。
  第一章、第二章是我自己写的，第三~六章多半是分派出去写的 —— 这两部分的可信度不一样，
  如果你在某个语法点里读出一句别扭的英文，告诉我关卡号和题号就行
- **一关里句子的骨架重复度偏高**：比如第 4-5 关（whose）是 8 句同一个框架换个名词。
  这当"句型操练"是够的，但不如「同一语法点出现在不同语境里」有价值。
  真要提升，方向是让每个语法点在陈述句/疑问句/否定句/不同主语里各出现几次
- **应用内的练习全都是「认出来」或「改错」，没有应用自己的自由产出**：
  最接近产出的是拼句，但词是给定的。写作那一步已经用「生成提示词、交给外部 AI 批改」
  的方式补上了（见上面「写作提示词」），但那**不是应用自己的能力** ——
  没有模型、没有批改、也不记录结果
- 段落排序每题只有 3~5 句，还不足以练习一整段真正的长段落。
  第七章也因此没有写作提示词 —— 那个语法点用单句/两句翻译练不到
- 地图是网格卡片，不是真正的「地图」（没有路径、没有节点连线）
- **错题本还没按记忆曲线排**：现在只按时间倒序，还没做到「隔几天再考你一次」
- 没有每日挑战、没有徽章、没有排行榜
- 时态里「一般过去 vs 现在完成」的语境对比做得不够，主要靠讲解文字
